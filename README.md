# sysmlv2-aas-transformation

WHAT IS INCLUDED
Model-driven-engineering artifacts
	AAS metamodel
	SysML Metamodel
	SysML v2 test suite
	AAS expected models
	Qvto transformation
Descriptive artifacts
	SysML v2 specification
	AASspecification
 
 
INSTALLATION REQUIREMENTS
To run the implementation we suggest you install the following:
    JavaSE-11
    Eclipse Version: 2021-03 (4.19)
    QVTo - https://projects.eclipse.org/projects/modeling.mmt.qvt-oml/downloads

INSTALLATION DETAILS
 
1.Import AAS metamodel and SyML v2 metamodel files in the workspace.
2.Run a new Eclipse instance.
3.Import the Qvto transformation and SysML v2 test suite
4.Run the Qvto transformation on the new instance with one of the models from SysML ve test suite folder as source model (eg., platform:/resource/sysml/src/training/01.package/Package Example.sysml)
